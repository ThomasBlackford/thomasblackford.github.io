Project Summary Document

Meeting the Specifications

General HTML/CSS Requirements

  • All pages use single header and footer components loaded from the components folder
  • Home page (index.html) has a proper layout with header, main, and footer sections
  • Navigation bar is consistent across all pages and loaded as a component
  • The site includes 5 pages total: Home, Towers, Crosspaths, Efficiency, and About
  • Footer includes reference to the developer (Thomas Blackford)
  • All pages include validation buttons for HTML, CSS, and WCAG

Dynamic Functionality

The website implements the following dynamic features using JavaScript:

  1. Rotating Fun Facts: The home page displays Bloons TD fun facts that automatically rotate every 5 seconds with a fade transition effect.
  2. Section Animations: Page sections animate into view as the user scrolls down the page using Intersection Observer API.
  3. Dynamic Component Loading: Header and footer components are loaded dynamically from separate files, allowing for consistent navigation and footer across all pages.

CRAP Principles

  • Contrast: The site uses a color scheme with strong contrast between text and background. Headers stand out with gradient backgrounds.
  • Repetition: Consistent styling is applied throughout the site with repeated design elements like buttons, cards, and section layouts.
  • Alignment: Content is properly aligned with a grid-based layout for tower cards and consistent margins/padding.
  • Proximity: Related elements are grouped together, such as navigation links and tower information cards.

Feedback and Updates

Based on peer critiques, the following updates were made:

  • Improved mobile responsiveness by adjusting the layout for smaller screens
  • Enhanced visual hierarchy with better section spacing and typography
  • Added more interactive elements to engage users
  • Implemented component-based architecture for better maintainability
  • Added validation buttons to ensure accessibility and standards compliance

Meeting Stakeholder Needs

The Bloons Money Maker Tool effectively meets the needs of Bloons TD players by providing a comprehensive resource for optimizing in-game income strategies. The tool offers detailed information about income-generating towers, efficiency comparisons, and crosspath recommendations.

Future plans for the website include:

  • Adding more detailed tower statistics and comparisons
  • Implementing an interactive calculator for income optimization
  • Creating user accounts to save preferred strategies
  • Adding a community section for strategy sharing
  • Keeping the content updated with new game updates and balance changes

The website's clean design, intuitive navigation, and focused content make it a valuable resource for both new and experienced players looking to maximize their in-game economy.
